# 🍕 Pizza Shop App
A simple Flutter application that allows users to order and customize pizzas through an easy-to-use interface.

## Features
- Select from multiple pizza types:
  - Margherita
  - pepperoni
  - Veggie
  
- Customize pizza size:
  - Small
  - Medium
  - Large
    
- Choose crust type:
  - Thin Crust
  - Thick Crust
  - Cheese Stuffed Crust
    
- Add multiple toppings
- View cart and order summary
- Place an order and receive a confirmation message

## Screens
1.	Menu Screen: Select a pizza and view cart items.
2.	Customize Screen: Configure size, crust, and toppings.
3.	Cart Screen: Review the order before checkout.
4.	Confirmation Screen: Displays a successful order confirmation.
   
## Technologies Used
- Flutter
- Dart

## Learning Objectives
This project demonstrates:
- Multi-screen navigation using Navigator
- Stateful and Stateless widgets
- Passing data between screens
- User input handling
- Radio buttons and ChoiceChips
- Cart and order management
- Flutter UI layout design using Rows, Columns, and Wraps
